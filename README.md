# My Todo

A sorting based personal todo system with categories, weekly and daily planning for Obsidian.

## Features
- **Categories:** Organize tasks into distinct categories with custom tags.
- **Weekly & Daily Planning:** Plan your week and assign tasks to your daily list.
- **Rollover System:** Automatically rolls over unfinished tasks or clears completed ones at a custom time.
- **Productivity Heatmap:** Track your daily task completion score to stay motivated.
- **Theme Compatibility:** Native Obsidian light and dark mode support with customizable accent colors.

## Installation

_Coming soon to Obsidian Community Plugins._

### Manual Installation
1. Download the latest release from the Releases page.
2. Extract the files (`main.js`, `manifest.json`, `styles.css`) into your vault's `.obsidian/plugins/my-todo` folder.
3. Enable the plugin in your Obsidian settings.
